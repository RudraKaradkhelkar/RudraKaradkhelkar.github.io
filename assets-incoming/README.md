# assets-incoming

Drop raw files here, in the subfolders below, using these file names. Fill in `ANSWERS.md` in this folder too. Everything in here except this README is gitignored, so originals and your answers never end up in the public repo. The content pass (`design-handoff/PROMPT-CONTENT-PASS.md`) strips metadata, crops, and copies processed versions into the site.

General rules for photos:

- Send the original file from the camera or phone, not a screenshot or a messaging-app copy (those are compressed).
- At least 2400 px on the long side (hero: at least 3000 px tall).
- No filters. Even light, in focus.
- Only photos you have the right to use, and that the people in them are OK with.
